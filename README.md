# EX No.6.2.DESIGN THE VARIOUS PARTS OF A MECHANICAL COMPONENT AND ASSEMBLE
## DATE:

## AIM: 
To Design the various parts of a mechanical component and assemble it using a bottom-up approach then convert it into the orthographic view

## REQUIREMENTS: 
1. Autodesk fusion 360
2. Windows 10
3. 4 GB of RAM (integrated graphics recommend 6 GB or more)
4. 2.5 Mbps or faster download; 500 Kbps or faster upload 

## COMMANDS USED:
### Align: 
The Align tool allows you to align, distribute or organize selected elements, annotations, tags and text along the axis you specify. Furthermore, the Arrange feature will automatically neatly place your tags around the current view.
The Align plug-in for Autodesk® Revit® can help to save time while producing complex drawings with large sets of annotation.
Just select a few elements and the Align tool will sort them for you.

### Derive:
Insert design elements such as Components, Bodies, Sketches, Work geometry, Flat patterns or parameters from another design.
The inserted elements update with changes to the original design

### Move: Moves the selected face, body, sketch, or construction geometry a specified distance or angle.
Select the objects to modify then specify the distance or angle. Use set pivot to reposition the manipulator

## PROCEDURE:

1. Launch the CAD software on the computer and create a new design 
or part file in the 3D modeling workspace. 
2. Set the default drawing units according to the given engineering 
drawing (millimetres or specified units) and review the front, side, top, 
and isometric views carefully. 
3. Identify the primary structural components of the chair, including the 
front legs, rear legs, seat frame, seat surface, backrest supports, and 
horizontal backrest bars. <img width="482" height="272" alt="Screenshot 2026-11-25 223325" src="https://github.com/user-attachments/assets/f78b1334-7804-4b77-886c-6b08b10a7309" />

4. Select the XY plane (or appropriate base plane) and enter the 
sketching environment to construct the base layout of the chair legs. 
5. Draw two rectangular profiles representing the cross-section of the 
rear legs using the rectangle and dimensioning tools, maintaining the 
exact spacing specified in the drawing. 
6. Apply geometric constraints to ensure both rear leg profiles are 
aligned and symmetrical, then finish the sketch.<img width="732" height="552" alt="Screenshot 2026-11-25 223728" src="https://github.com/user-attachments/assets/974f49ca-d3b3-445a-b489-6afafa93d2f3" />
 
7. Use the Extrude command to raise the two rear leg profiles to the 
required height, forming the solid rear vertical members. 
8. Create a new sketch on the base plane and draw two rectangular 
profiles for the front legs at the specified distance from the rear legs. 
9. Dimension the cross-section and spacing of the front legs 
accurately, finish the sketch, and use the Extrude command to 
generate the solid front legs to their required height.<img width="432" height="526" alt="Screenshot 2026-11-25 223859" src="https://github.com/user-attachments/assets/891004b3-b3cb-4da0-a88f-7e113effd53b" />
 
10. Select the upper inner faces of the legs at the seat level and start 
a new sketch to construct the seat frame connecting all four legs. 
11. Use the line, rectangle, and trim tools to define the closed 
boundary of the seat frame, apply dimensional constraints, and finish 
the sketch. 
12. Use the Extrude operation to give the seat frame a thickness of 6 
units (or as specified in the drawing) to firmly join the front and rear 
legs. 
13. Select the top face of the seat frame and create a new sketch for 
the main seat surface. 
14. Draw a rectangular profile matching the outer length and width of 
the seating area, apply necessary constraints, and extrude it to form a 
flat, solid seat top. <img width="307" height="1078" alt="Screenshot 2026-11-25 223948" src="https://github.com/user-attachments/assets/500e2422-596f-42b8-be1e-6743e3251cb8" />

15. Select the side plane or the top face of the rear legs to create a 
sketch for the backrest supporting members extending upward from 
the rear legs. 
16. Position and incline the backrest supports according to the angle 
and side-view dimensions shown in the drawing, then extrude them to 
match the thickness of the rear legs. 
17. Create a sketch on the front or rear face of the backrest supports 
to draw the horizontal backrest bars (slats) at the specified vertical 
heights. 
18. Use the Extrude tool to give the horizontal backrest bars their 
required thickness, connecting the left and right backrest supports. 
19. Select the Fillet tool and apply smooth rounded edges to the seat 
corners, backrest bars, and outer leg edges as indicated in the 
engineering drawing. 
20. Inspect the completed 3D model using front, side, top, and 
isometric views, verify all dimensions, apply a wooden material 
appearance, and save the final CAD file.


### Note: 
If the components do not fit properly into the slots, it can be moved into the slot using the Move option.
